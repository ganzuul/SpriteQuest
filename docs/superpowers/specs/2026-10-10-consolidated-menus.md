# Consolidated Lattice menus

User approved the Consolidated Menus proposal and implementation in an isolated worktree on 2026-10-10. This supersedes the audit's initial preference for eight categories.

Ship six categories: File, Edit, View, Graph, Workflow, Help. Preserve assets/lattice-logo.svg. Give top-level targets at least 68 px width and 4 px gaps at desktop widths; wrap with 64 px targets on narrower screens. Dropdown rows are 34 px on precise pointers and 44 px on coarse pointers, with aligned icon/state, label, shortcut and caret columns and task separators.

Menus start closed. Opening one arms hover switching until an action, toggle or radio is chosen, outside pointerdown, Escape, Tab or resize dismisses it. Submenu navigation does not disarm it. Hover alone cannot restart it. Keyboard navigation uses arrows, Home/End, typeahead and Enter/Space, with focus restored appropriately. While a popup is open, isolate menu keydown/keyup/paste from graph listeners; Delete, C, F and clipboard/history shortcuts cannot act on the background graph. After dismissal, normal clipboard/history accelerators work even when focus returns to a menu root.

File owns New/Open/Examples, Save to workspace/Duplicate/Rename, Import into current graph/Export portable workflow, Delete workflow/Close. Edit owns Undo/Redo, Cut/Copy/Paste/Duplicate/Delete selection, Select all/Clear selection. View owns Details/Preview/Shelf toggles, Follow/Pin, Fit graph/Fit selection/Center selection/Zoom, Reset layout and Theme. Graph owns Add/Details/Rename, Group/Ungroup/Create subgraph/Save subgraph, comments/portals, Select/Pan/Compact. Workflow owns Assign/Clear/Arm, validation/root-result navigation/Stop, diagnostic Run to current output/Run details and Configure submenu (Workflow Data/Fast connections/Recall). Help owns guide/node reference/shortcuts/About.

Reuse existing mutation and preview handlers. Derive disabled state from exact selection, read-only capability, output readiness and owned root activity. File commands target the saved root; graph commands target the active view. Never start unified generation from a menu: it starts with ordinary SillyTavern Send. Diagnostic runs retain request-bound checks; Apply/Reject remain result-specific and visible. Stop must reflect owned activity and cannot cancel an unrelated workflow.

Remove the duplicate Examples location, Details Duplicate/Delete overflow and permanent Portals header button. Simplify preview tracking to a labeled pin control with follow-by-default and a chevron collapse action. Preserve root selector, child tabs, contextual actions, visible Arm/Stop, current run meter, review actions and standard Close. Keep Undo/Redo and Details quick controls in this pass (their removal was optional). Persist node shelf visibility alongside preview layout, and reset panel geometry/visibility without changing content or camera.

Expose real supported behavior only. Include small integrations depicted in the proposal: clear assignment, shelf visibility, reset layout, read-only validation report and Help views. Find Node, upstream/downstream traversal, subgraph manager, command palette, historical runs and baseline comparison are follow-up scope. Legacy backend/data migration is independent; retained legacy roots remain accessible through saved selection, but new menus do not promote legacy creation or ambiguous unified Run.

Verification: real unit/controller tests for capability gating and mutations; browser tests for click/hover/reset, submenu behavior, focus, graph isolation, pane persistence/reset and root/child targeting; narrow/high-DPR visual capture; full unit suite, type checking, build, asset checks and browser suite. No model calls or external writes in tests.
