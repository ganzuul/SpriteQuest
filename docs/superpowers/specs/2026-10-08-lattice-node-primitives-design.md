# Lattice deterministic node primitives

The user approved building and integrating Compose, Text Rules, JSON Decode and Select Fields on 2026-10-08, and authorized direct coordination with Architecture. Context Join remains part of Architecture's existing scope. This document makes the approved design concrete for implementation and review.

## Concurrent ownership

Build new operation modules and their dedicated tests on `codex/lattice-node-primitives`. Architecture owns the shared catalog, artifact kinds, ports, runtime, package validation, subgraphs and workspace UI until its prototype contracts settle. Do not edit Architecture's checkout. Integrate only after an agreed handoff; no competing executor, migration or release.

All four nodes are deterministic, make zero model requests, have no host effects and do not mutate inputs. Failures are Result values, never partial authoritative output. Text is an intermediate string; Draft retains its original host source. Data is bounded plain JSON, independent of graph/package sanitization. JSON object keys such as `token` remain legitimate runtime data; reading them must not enable prototype traversal or unsafe assignment.

## Boundaries

Pure operation APIs return `{ok:true,data:{...}}` or `{ok:false,error:{code,message,...}}`. Successful data includes a bounded `report` array. Do not import the catalog, runtime, host or UI in these modules. Use the repository's JavaScript ES modules and node assertion tests, with JSDoc/declaration contracts rather than introducing a validation dependency or a second build system.

Production local JavaScript imports retain the installed asset cache suffix `?v=0.19.1`; Architecture updates these with the final release version. Test imports need no suffix.

Text input/output: at most 100,000 UTF-16 units. JSON serialized input/output: at most 262,144 UTF-8 bytes, depth 32 and 10,000 visited values. Reject cycles, accessors, sparse arrays, nonfinite numbers, nonplain objects and unsupported values. Read own data properties only. Clone output rather than returning mutable aliases. Do not truncate to satisfy a limit.

## Compose

`composeText({template?,sections?,data?,separator?})` returns `{text,report}`. Sections are an ordered array of `{name,text}` (at most 64, unique identifier names). Without a template, join their text in that order with separator (default two newlines). With a template, expand `{{section:NAME}}` and `{{data:/JSON/Pointer}}`; `{{{{` escapes a literal `{{`. Pointer follows RFC 6901, including empty pointer for the entire value. Strings insert as text; other JSON values serialize. Missing sections/paths fail; no eval, arbitrary expressions, recursive expansion or host macros. Text mode publishes Text; Guidance mode wraps the same text as Guidance for the existing publisher during integration.

## JSON Decode and Select Fields

`decodeJson(input,{mode='parse',schema?}={})` returns `{value,report}`. Parse accepts only raw JSON text (no code-fence removal or repair). Check accepts JSON values and clones them. Validate an explicitly documented schema subset: `type` (one type), `enum`, `const`, `properties`, `required`, boolean `additionalProperties`, single-schema `items`, `minItems`, `maxItems`, `minLength`, `maxLength`, `minimum`, `maximum`. Metadata `title`, `description`, `$schema` is accepted but does not change validation. Unknown keywords and external references fail, so unsupported validation never silently passes. Type values are null, boolean, object, array, number, integer and string. Schema depth is at most 16 and at most 1,000 schema nodes. Limit findings to 128 with paths; schema mismatch fails with findings available in the error. No coercion, repair, retries or paid calls.

`selectFields(value,{fields})` returns `{value,report}`. Fields (at most 128) are `{name,path,required?,default?}`; name is a unique nonempty output key, path is an array of string keys or nonnegative integer indices, required defaults true. Read nested own fields, including JSON keys named `constructor` or `__proto__`, without reading inherited properties. Missing required fields fail; optional fields omit unless an explicit default is supplied. Defaults also pass JSON boundaries. Selected values are cloned into a new object using safe data-property creation. Empty path selects the whole value. No expression language or implicit flattening.

Shared `json-data.js` exposes `cloneJsonValue(value)` returning `{value}` in a Result and `readJsonPath(value,path)` returning `{found,value?}` in a Result. These are runtime data helpers, not graph sanitizer changes.

## Text Rules

`applyTextRules(text,settings={},execution={})` and `createDraftRulePatches(draft,settings={},execution={})` are asynchronous Result APIs. Settings contain `mode` (`replace` default or `extract`), ordered `rules` (at most 64), and extraction separator (default newline). Rule is `{kind:'literal'|'regex',pattern,replacement?,flags?}`. Patterns are nonempty and at most 2,048 UTF-16 units; regex flags accept only i, m, s, u (unique) with global matching implicit. Literal matching accepts i and u only. Replace uses standard replacement captures; literal replacement remains literal. Extract joins whole matches in rule order; it is Text-only. Reject zero-width matches. Bound total findings to 4,096 and aggregate output to the text limit.

Run untrusted regex in a dedicated terminable module Worker, with default timeout 1,000 ms (configurable 100..2,000 via execution options) and optional AbortSignal. Always terminate on completion, failure, cancellation or deadline. A Worker factory can be injected for real Node worker tests; the browser default uses a Vite-compatible module Worker entry. There is no unbounded fallback on the UI thread. Return `WORKER_UNAVAILABLE`, `RULE_TIMEOUT`, `ABORTED` or `INVALID_RULES` as appropriate. Findings describe rule index, segment index and UTF-16 positions in the segment at that rule's turn, not frozen original offsets after sequential transforms.

Draft mode only supports replace. Frozen draft text must equal `source.originalText`. Existing editable spans remain exactly the original authorized spans; transform each independently and emit at most one patch per changed span using its original index. A raw Draft without spans gets one explicitly whole-text original span (empty input gets no spans); scoped Draft without spans must fail rather than widening permissions. Validate the proposed envelope through existing `validatePatches`, including protected literal preservation, before returning it. Reject blank replacements incompatible with that gate. Return `{artifact:{kind:'patches',draft,patches,protectedLiterals},report}`; never return a directly applicable rewritten Draft. Downstream Validate Patches -> Review Gate -> Apply Reply remains mandatory. Text mode may delete and extract freely within limits.

Architecture confirmed on 2026-10-08 that it owns core integration and final release checks after reviewed module handoff. This branch supplies an isolated adapter, not edits to its core files. `operations/nodes.js` exports plain `PRIMITIVE_OPERATIONS` metadata, `describePrimitive(node,{phase}) -> Result<{descriptor,ports}>`, and `executePrimitive(node,namedInputs,execution={}) -> {ok:true,artifact,reports:[]} | {ok:false,error}`. Port descriptors use the current core field `kind`, plus id, label, direction, required and cardinality (`one`). Output port is `out`. Text artifacts are `{kind:'text',text}`; Data artifacts are `{kind:'data',value}`. Model role is null and terminal is false.

Compose adapter config: `mode` join/template, `outputKind` text/guidance, template, sections, separator. Optional input `data` accepts Data; optional input `section.NAME` accepts Text for each configured section and overrides that section's constant text. Configured section names are stable identifiers, so changing order preserves pins. Text Rules config inputKind text/draft and mode replace/extract; one required `in`, one `out`; Draft is post-only and emits patches. JSON Decode config mode parse/check and optional schema JSON text (empty means absent); one required Text/Data `in`, Data `out`. Select Fields uses configured fields, required Data `in`, Data `out`. No unsupported or stale named input is silently consumed. Metadata lists explicit enum/text/JSON controls without importing UI. The core may adapt the JSON editor descriptors to its UI control model.
