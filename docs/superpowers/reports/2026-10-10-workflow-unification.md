The implementation replaces mutually exclusive Pre/Post assignments with one native workflow spanning preparation, ordinary SillyTavern generation, composable reply processing, review and accepted consequences. Original native replies remain available; applying the reviewed result creates a new swipe. Legacy pre/post packages remain supported, with explicit authoring of a unified copy.

- Thirty-one executable unified examples beside thirty legacy lessons, including the motivating scenes and ten additional output flows.

## Supported boundaries

Story Documents are authorized user/chat/actor logical targets stored in host metadata, rather than arbitrary operating-system paths. Imported file snapshots grant no write access. Format supports bounded JSON, JSONL, text, Markdown and CSV schemas. Conflicts hold; there is no automatic rebasing of dependent narrative or atomic multi-target persistence claim. Known failed targets can retry without repeating models, draws or publication; unknown saves remain held.

Native generation supports one ordinary nongroup reply or newly generated swipe. The installed-host test uses the actual public helpers and an isolated host event emitter with synthetic replies/model output/save acknowledgements. It does not invoke paid providers, streamed native Generate or real durable persistence. The host chat is restored and Story-2 remains untouched. Jev/Laya transports and configuration are validated through boundary fixtures; live provider availability or latency is not claimed.

Story time advances from explicit or validated authored evidence, not wall-clock time or message count. Actor access requires loaded canonical identity and live participation; private reflections need author permission. Relationship scores remain portrayal guidance and do not grant consent or action authority.
