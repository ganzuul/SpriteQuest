01 / The gap

We can enter a place.
We cannot yet find it in the world.

Today, an outdoor heightfield can host a building plan. The missing link is the regional map's position in a larger atlas.

What works now
⌂

Terrain → floorplan

A build plate anchors the Customs House floorplan at a measured location on Border March terrain.

What is missing
◎

World → regional terrain

Scenes name a world, but no parent map says where Border March sits, how large it is, or which routes lead beyond it.

A picture can be beautiful and still have no address.

Prototype premise: maps are linked records with explicit transforms. Their illustrations are views of those records, not substitutes for them.

02 / The scale register

One atlas. Several canvases.
Every transition has an address.

Each scale owns the information it can responsibly represent. Parent links connect the leaves without flattening the world into one unwieldy map.

Scale 01WorldNamed lands · long routes · broad uncertainty
Scale 02RegionSettlements · passes · travel corridors
Scale 03Local terrainMetric heightfield · hazards · traversability
Scale 04InteriorRooms · portals · scene positions
⌖

Stable anchors

A region links to a parent by a transform: position, orientation, represented extent, and coordinate reference.

↗

Routes are records

Travel time, direction, and standing belong to route data. A dotted line in an image cannot make a route real.

◌

Uncertainty is visible

Rumored, observed, charted, and warranted are distinct states—not a single “connected” flag.

Demonstration geography is illustrative except where it reuses existing Border March data.

The Locus Frame is a region, not a promise.

            
MOSS's boxes guide where an item belongs in the image. They do not encode a road's exact course or prove that two endpoints connect. For exactness, draw those from map data after the style pass.

            
Scale rule: Layouts are flat. World, regional, local, and interior maps each get their own canvas; parent transforms are applied before making that canvas.

          

        

      

    


    

      

        
05 / Standing, evidence, and canon

        
An image may be persuasive.
It is not a warrant.

        
The Bureau distinguishes a measured place from a convincing depiction of one. Generated art can suggest revision; only authored evidence changes the atlas record.

        

          

            
Field noteUnverified route or landmark claim. Visible as uncertainty; excluded from confirmed topology.

            
ObservedSeen or measured in-world. Attached to source and location; still not automatically canon.

            
WarrantedCurated and reviewed by an author. Eligible to appear as a certified atlas feature.

            
CanonStable map facts and relationships. Generated images never promote themselves here.

          

          

            

              Map art cannot silently rewrite map data.
              
Every render keeps its source-map revision, scale, prompt/layout draft, seed, model settings, and output reference. A missed anchor becomes a render discrepancy to review—not a new world fact.

            

            

              DIEGETIC TRANSLATION
              
Witness plate ≠ witness testimony

              
A plate guides the illuminator. A surveyor's signed observation records what was actually found. Confusing the two is how rumors acquire roads.

            

          

        

      

    


    

      

        
06 / First-pass product specification

        
What this prototype proposes
for a SillyTavern extension.

        

          
MUST · MAP TREE
Browse World → Region → Local Terrain → Interior, with stable IDs and explicit parent transforms. Each leaf has a distinct scale, extent, orientation, and coordinate system.

          
MUST · NAVIGATION
Enter child maps through named anchors; return through breadcrumbs. A portal or route records both endpoint map IDs and endpoint locations.

          
MUST · AUTHORITY
Structured map data owns geometry and topology. MOSS output is a replaceable visual artifact with provenance; it cannot change the underlying map.

          
MUST · ILLUSTRATION
Generate one MOSS Layout per canvas from projected feature boxes; optionally supply relief as a reference. Overlay exact labels and routes deterministically.

          
MUST · REVIEW
Show evidence/standing, source revision, generated status, and discrepancies. Unknown and rumored connections stay visually distinct from charted routes.

          
NOT V1
Automatic world synthesis, diffusion-authored topology, seamless infinite zoom, live travel simulation, and claims that bounding boxes guarantee exact placement.

        

        
Decisions for the presentation room
Who edits map geometry? Is world scale topological first, or should it also have coarse terrain? Which evidence states should players see? Should MOSS render on demand or as a reviewed batch?

        
Draft status: interaction model and authority boundaries are proposed; atlas schema, editing workflow, persistence, and ComfyUI integration remain to be specified.
